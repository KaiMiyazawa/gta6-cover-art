Neon Vice Cover Studio turns your photos into GTA-style multi-panel cover art: pick a layout, drag to crop each panel, apply a neon-sunset grade and bold caption lettering, then export the finished cover as a PNG (1080×1080, 1080×1350 or 1920×1080). Fully offline, with no Rockstar logos, artwork or fonts.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080. Add `?demo=1` to load a finished sample cover.
